# OpenChat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the OpenChat Android app (package `com.piptechnologies.openchat`): open a chat with any number, read WhatsApp messages without blue ticks, recover deleted messages and media, run a second account in a WebView — every screen and state of the design, green CI on `main`, one Paparazzi PNG per screen/state on the `screenshots` branch.

**Architecture:** Single Gradle module, MVVM with one Hilt `ViewModel` per screen and stateless Compose screens (`XScreen(state, callbacks)`) wrapped by thin `XRoute` composables. A pure-Kotlin `core` package (no Android imports) holds the logic that carries the unit tests; `data` (Room + DataStore + repositories) and `platform` (Android helpers) sit under it; two Android services (notification listener with the media watcher, and the web-session foreground service) feed the repositories. Screens read repositories through their ViewModel only.

**Tech Stack:** Kotlin 2.0.21, Jetpack Compose (BOM 2024.12.01, Material 3), Hilt 2.53.1 (KSP), Room 2.6.1 (KSP), DataStore Preferences 1.1.1, Coil 2.7, Navigation Compose 2.8.5, Coroutines/Flow, Paparazzi 1.3.5, JUnit 4, AGP 8.7.3, Gradle 8.10.2, minSdk 24, targetSdk/compileSdk 35.

**Spec:** `docs/brief.md` (the product brief, binding) and `docs/design-map.md` (the design mapped screen by screen, with the rulings R1–R17). Section numbers below (§4.3, §5.1 …) refer to `docs/design-map.md`. The raw prototype is at `docs/design/Prototype.dc.html`.

## Global Constraints

- Package `com.piptechnologies.openchat`; single module `:app`; minSdk 24; targetSdk 35; compileSdk 35; debug builds only, no release keystore, never publish.

- Strings are English resources in `res/values/strings.xml` (`stringResource`), verbatim from the design map. Only English ships (R13).
- Screenshot tests: package `com.piptechnologies.openchat.screenshots`, class names end in `ScreenshotTests`, one `@Test` per screen/state named exactly as the file in §6 (e.g. `home_empty`), `paparazzi.snapshot { OpenChatTheme { … } }`, device `ScreenshotDevice.paparazzi()`. ## Review Focus

1. Paste of "+44 (0)20 7946 0958" must set United Kingdom and the field "20 7946 0958" (trunk zero dropped, no double country prefix) — test in Task 1.
2. A WhatsApp notification that only updates an already-stored line (same timestamp, same text) must not create a duplicate message or a false "deleted" — test in Task 3.
3. A media file that WhatsApp deletes before the first reconcile ever saw it must not crash or produce a phantom item; a file present on two roots must be one item — tests in Task 4.
4. Sending when no messaging app is installed must open the web link in the browser and never crash on `ActivityNotFoundException` — Task 7 (`SendLauncher`) handles both.
5. Storage permission missing on API 33+ must leave the Deleted media screen usable (empty state with "Allow media access"), never a crash in the watcher — Task 9 checks `StoragePermissions.hasAll` before touching storage; Task 15 renders the state.

```kotlin
package com.piptechnologies.openchat.core.phone

/** Result of normalising pasted/typed text: [country] is null when the current country should stay. */
data class NormalizedPaste(val country: DialCountry?, val nationalDigits: String)

object PhoneNumberNormalizer {
    const val MAX_DIGITS = 15
    fun digitsOnly(text: String): String
    /** §5.1: strips spaces, dashes, dots, parentheses, a leading "+" or "00"; "+"/"00" → longest dial-code match sets the country and is stripped; one leading trunk "0" is dropped; capped at MAX_DIGITS. */
    fun normalizePaste(raw: String, current: DialCountry): NormalizedPaste
    /** Drops exactly one leading "0" when there is more than one digit. */
    fun stripTrunkZero(national: String): String
    /** "81234567890" → "812 3456 7890" (first 3, next 4, rest). */
    fun group(national: String): String
    fun e164Digits(dialCode: String, national: String): String   // dialCode + national
    fun displayInternational(dialCode: String, national: String): String   // "+62 812 3456 7890"
}

object RelativeTime {
    /** Recent rows: "Now" (<60 s), "5m", "2h" (same calendar day), "Yesterday", weekday "Mon" (<7 days), else "22 Sep". */
    fun label(timestampMs: Long, nowMs: Long, timeZone: java.util.TimeZone = java.util.TimeZone.getDefault(), locale: java.util.Locale = java.util.Locale.US): String
    /** "14:26" (24 h clock). */
    fun clock(timestampMs: Long, timeZone: java.util.TimeZone = java.util.TimeZone.getDefault(), locale: java.util.Locale = java.util.Locale.US): String
    /** Inbox rows: "14:26" today, "Yesterday", "Mon" (<7 days), else "22 Sep". */
    fun conversationTime(timestampMs: Long, nowMs: Long, timeZone: java.util.TimeZone = java.util.TimeZone.getDefault(), locale: java.util.Locale = java.util.Locale.US): String
    /** Media day groups: "Today", "Yesterday", else "Mon 22 Sep". */
    fun dayLabel(timestampMs: Long, nowMs: Long, timeZone: java.util.TimeZone = java.util.TimeZone.getDefault(), locale: java.util.Locale = java.util.Locale.US): String
}
```

```kotlin
package com.piptechnologies.openchat.core.messages

enum class MessageKind { TEXT, PHOTO, VIDEO, VOICE, AUDIO, DOCUMENT, STICKER, GIF, CONTACT, LOCATION, DELETED, OTHER }

data class CapturedMessage(
    val id: Long, val appPackage: String, val conversationKey: String, val conversationTitle: String,
    val sender: String?, val text: String, val kind: MessageKind, val timestamp: Long,
    val seenLocally: Boolean, val deletedAt: Long?, val mediaId: Long?,
) { val isDeleted: Boolean get() = deletedAt != null }

/** One message line of a posted notification (MessagingStyle message or a plain text line). */
data class NotificationLine(val text: String, val timestamp: Long?, val sender: String?)

object NotificationText {
    const val WHATSAPP = "com.whatsapp"
    const val WHATSAPP_BUSINESS = "com.whatsapp.w4b"
    val watchedPackages: Set<String> = setOf(WHATSAPP, WHATSAPP_BUSINESS)
    /** True for bundle summaries and status lines: "12 messages from 2 chats", "You have 3 new messages", "Checking for new messages", "You may have new messages", "N new messages", titles equal to "WhatsApp"/"WhatsApp Business" with such text, "Tap to view", "Backup in progress", "Finished backup", "Restoring", "Calling…", "Incoming voice call", "Ongoing voice call". */
    fun isSummaryOrNoise(title: String, text: String): Boolean
    /** "This message was deleted" and localized variants (see docs/design-map.md §5.2), with or without a leading 🚫 and trailing period, case-insensitive. */
    fun isDeletedPattern(text: String): Boolean
    /** Kind from the text prefix: 📷/"Photo" → PHOTO; 🎥/"Video" → VIDEO; 🎤/"Voice message" → VOICE; 🎵/"Audio" → AUDIO; 📄 or "Document" → DOCUMENT; "Sticker"/🧩 → STICKER; "GIF" → GIF; 👤/"Contact" → CONTACT; 📍/"Location"/"Live location" → LOCATION; deleted pattern → DELETED; else TEXT. Matching is on the trimmed text: exact word or emoji prefix, case-insensitive. */
    fun kindOf(text: String): MessageKind
    fun conversationKey(appPackage: String, title: String): String   // "$appPackage|${title.trim().lowercase()}"
    /** Digits when the title is a phone number (starts with "+" or is ≥ 7 characters of digits/spaces/dashes/parentheses), else null. */
    fun phoneNumberFrom(title: String): String?
    /** Avatar initial: "#" when the title starts with "+" or a digit, else the first letter uppercased ("?" when empty). */
    fun initialFor(title: String): String
    fun textHash(text: String): Int = text.trim().hashCode()
}

object DeletedMessageDetector {
    /** Ids of [stored] (not yet deleted) messages that the latest [incoming] lines show as deleted. Timestamped deleted lines match by |Δt| ≤ [toleranceMs]; untimestamped ones match the stored message at the same position from the end that is no longer present verbatim. */
    fun detect(stored: List<CapturedMessage>, incoming: List<NotificationLine>, toleranceMs: Long = 2_000): List<Long>
    /** Incoming lines that are neither deleted-pattern nor already stored (same trimmed text and, when both have timestamps, |Δt| ≤ tolerance). */
    fun newLines(stored: List<CapturedMessage>, incoming: List<NotificationLine>, toleranceMs: Long = 2_000): List<NotificationLine>
}

enum class InboxMode { ALL, DELETED }

data class ConversationSummary(
    val key: String, val title: String, val phoneNumber: String?, val initial: String,
    val lastTimestamp: Long, val preview: String, val previewDeleted: Boolean,
    val unreadCount: Int, val deletedCount: Int, val colorIndex: Int,
)

object InboxBuilder {
    /** Groups by conversationKey, newest first. ALL: every conversation, preview = latest message text, unreadCount = !seenLocally. DELETED: only conversations with deleted messages, preview = latest deleted text. colorIndex = Math.floorMod(key.hashCode(), 5). */
    fun build(messages: List<CapturedMessage>, mode: InboxMode): List<ConversationSummary>
}
```
