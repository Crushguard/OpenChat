## Architecture decisions (pinned)

1. **UiText.** ViewModels never resolve user-visible text with the application context (on API 24–32 the
   AppCompat per-app locale does not reach it, and resolved strings in retained state go stale after a
   language switch). They expose `UiText` (state and toasts); composables resolve it with `asString()`.
   `ui/components/UiText.kt`:
   `sealed interface UiText { data class Res(@StringRes val id: Int, val args: List<Any> = emptyList()); data class Plural(@PluralsRes val id: Int, val count: Int, val args: List<Any> = listOf(count)); data class Raw(val value: String) }`,
   `fun uiText(@StringRes id: Int, vararg args: Any): UiText`, `fun pluralText(@PluralsRes id: Int, count: Int, vararg args: Any): UiText`,
   `@Composable fun UiText.asString(): String`, `fun UiText.asString(context: Context): String` (args that are
   UiText resolve recursively). Outbound intents that carry user-language text (share text) resolve with
   `Context.withAppLocale()` (`ui/components/AppLocaleContext.kt`), a configuration context carrying
   `AppCompatDelegate.getApplicationLocales()` when set. Support-facing text (email subject, rating/version
   lines) stays English and non-translatable.
2. **Time labels.** `core/phone/RelativeTime` keeps its functions and English defaults (tests) and gains
   `words: TimeWords = TimeWords.ENGLISH` plus locale-driven weekday/month names and a `dayMonthPattern`
   parameter; `MediaDayGrouper.group` gains `words`. `data class TimeWords(val now: String, val today: String,
   val yesterday: String, val minutesAgo: (Long) -> String, val hoursAgo: (Long) -> String)`. The UI uses
   `@Composable fun rememberTimeFormatter(): TimeFormatter` (`ui/components/TimeFormat.kt`) built from string
   resources and `LocalConfiguration.current.locales[0]` (best date pattern for the locale); clock stays 24 h
   (design).
3. **Bidi.** `fun ltr(text: String): String` (`ui/components/Bidi.kt`) wraps phone numbers, dial codes and
   other left-to-right tokens in LRI…PDI isolates; the phone input row is laid out LTR.
4. **Mirroring.** Directional Lucide icons build with `autoMirror = true` (arrow-left/right, chevron-left/right,
   arrow-up-right, external-link, log-out, send, send-horizontal, and any other arrow the code uses).
5. **Effective language.** AppCompat's application locales are the source of truth (like RecoverMe):
   `Languages.current(context)` = the explicit per-app choice if any, else the best match of the device
   locales among the 19 (exact tag, `in`↔`id` and `iw`↔`he` aliases, then language only, e.g. pt-PT→pt,
   pt-BR→pt-BR, zh-TW→zh), else English. `res/xml/locales_config.xml` + `android:localeConfig` expose the
   set to Android 13+ per-app language settings; `resourceConfigurations` strips library translations
   outside the set (like Status Saver's `localeFilters`).
6. **Translatability rules** for every English string: full sentences per state (no concatenated fragments or
   inserted lowercase nouns), counts as `<plurals>`, positional `%1$s` when a string has 2+ arguments,
   translator comments on short or ambiguous strings, brand names untranslated.

## Waves

- **V0 (parallel):** V0-foundation (decisions 1–5 infra + shared strings + non-translatable marks +
  locales config + LocalesConfigTest); V0-research (WhatsApp's own "This message was deleted" and
  notification noise texts in the 19 languages, with sources).
- **V1 (parallel vertical slices, disjoint files):** home, messages, media, second+gate+launch, settings,
  listener. Each: UiText, localized time labels, `ltr()` for LTR tokens, RTL audit (rendered RTL in the
  desktop harness), translatability audit of its strings file, English screenshots unchanged.
- **V2 (parallel):** six translation agents (three locales each) writing `values-<q>/strings*.xml` mirroring
  the six English files; V2-verify (TranslationCompletenessTest, scenes extraction + Paparazzi locale matrix
  for all 34 screens × 18 locales, CI collection into `screenshots/locales/<tag>/`); V2-e2e (emulator
  end-to-end suite on API 30 and 34 with a CI-only WhatsApp stand-in app that posts MessagingStyle
  notifications and writes/deletes media, walking every screen and every language, device screenshots).
- **V3:** reviews (slices, translations by language group, verification), CI green on main, README,
  final whole-branch review, final report.
