# OpenChat

Native Android companion app for WhatsApp: open a chat with any number, read without blue ticks,
recover deleted messages and media, and run a second account. Everything stays on the device.

Package `com.piptechnologies.openchat` · Kotlin · Jetpack Compose · Material 3 · minSdk 24 · targetSdk 35.

This README is filled in as the build progresses (build, install, Notification Access, per-tool test notes).
